## 🌐 Website Architecture & Visual Design

This website is crafted as a self-contained, high-performance portfolio:
- **Aesthetic:** Editorial Fashion × Digital Minimalism (dark navy ink frames, soft blue-white backgrounds, dramatic typography).
- **Typography:** Cormorant Garamond (italic display), Playfair Display (headings), DM Mono (labels/code), and Jost (body).
- **Interactive Features:**
  - 6-column rising photo frame parallax in the Hero section.
  - Interactive project detail modals with technical tables and direct links.
  - Smooth parallax typography headings via `requestAnimationFrame`.
  - Staggered scroll reveals with `IntersectionObserver`.
  - Mobile slide-in drawer and tailored responsive single-column layouts.

### Running Locally
To view the portfolio locally:
1. Double click `index.html` to open directly in any modern browser.
2. Or run a local HTTP server:
   ```bash
   python -m http.server 8080
   ```
   and navigate to `http://localhost:8080/index.html`.
